Not medical advice. A student project trained on a public Kaggle dataset of about 100,000 records. It can be wrong in both directions, and it flags generously, so false alarms are more common than misses. Only a doctor and a lab test can tell you if you have diabetes. The server is on a free plan, so the first check can take up to a minute.
